網管資安終端維運與進階稽核指令庫 (點擊即可複製)

整合 MIS 網管、系統管理員與資安專家的核心終端指令。分類明確，原生 APP 解鎖級別（點擊卡片代碼立即複製到剪貼簿）。

一、基礎連線、連線路徑與 DNS 深度除錯
Win/Linux
ping 8.8.8.8 -t
【持續高頻探測】向外部核心閘道發送不中斷 ICMP 請求，用於測試骨幹網路有無瞬斷、封包隨機丟失。
Windows
tracert -d 1.1.1.1
【路由躍點追蹤】不解析主機名稱(-d)跳過逆向 DNS，以極快速度抓出封包經過的外網節點，確認路由中斷點。
Windows
pathping 8.8.8.8
【節點遺失率計算】結合 Ping 與 Tracert。發送高密度探測並統計各個節點的獨立丟包率，精準揪出內網瓶頸。
Win/Linux
nslookup -type=mx su.domain.local
【MX 郵件路由查詢】專用於排除企業內部 Mail Server 傳遞故障，指定檢查目標網域的郵件交換紀錄。
二、網卡配置、網段 IP 釋放與本地 DNS 快取刷新
Windows
ipconfig /all
【網卡全細節】完整印出所有實體與虛擬介面卡、實體 MAC 位址、DHCP 租約過期時間與主要/次要 DNS。
Windows
ipconfig /flushdns
【DNS 快取重置】強制刷新並清空本機 DNS 解析快取。當內網主機變更 IP 卻遲遲導向舊位址時必用。
Windows
ipconfig /release & ipconfig /renew
【DHCP 重新釋放與索取】一鍵放棄當前遭指派的內網 IP，並向 DHCP 伺服器重新發送 Discover 要求。
Windows
ipconfig /displaydns
【本地解析快取稽核】印出當前作業系統記憶體中留存的網域解析對應表，用以鑑識是否有潛在惡意劫持。
三、L2 實體拓撲、連接埠監聽、行程 PID 對應（MIS/資安高階）
Win/Linux
arp -a
【ARP 實體快取快照】列出 L2 區域網路內近期所有溝通過的裝置 IP 與其真實對應的實體 MAC 晶片位址。
Windows
netstat -anob
【高管理員權限】列出系統目前所有建立的 TCP/UDP 連線、監聽 Port，並強行標註該連線是由哪個「執行檔(EXE)」發起。
Windows
arp -d *
【高權限 - 清空 ARP】強制抹除全機 ARP 對應表。當區網疑似遭到 ARP Spoofing (中間人攔截攻擊) 時用於重置。
Windows
Get-NetTCPConnection -State Listen | ft
【PowerShell 監聽稽核】以清晰的表格格式，過濾並僅印出目前主機作業系統中所有對外敞開、呈現 Listen 狀態的埠口。
四、企業帳號權限、Active Directory 與網域稽核
Windows
net user admin_username /domain
【網域用戶權限審查】在網域控制站 (DC) 下直接查詢指定帳號的詳細屬性、密碼過期日、所屬全域群組。
Windows
net localgroup administrators
【本機管理員權限審查】嚴格核對本機電腦的管理員群組成員，揪出被惡意塞入或私下加開的高權限暗門帳號。
Windows
gpresult /h gpreport.html
【GPO 網域群組原則鑑識】匯出此電腦目前實質生效的 GPO 原則報告至 HTML 檔，用以排除防毒或權限派送障礙。
Windows
wmic useraccount get name,sid,status
【用戶 SID 安全清查】撈取系統上所有使用者帳號，包含其資安核心識別碼 (SID) 還有目前是否處於停用或啟用狀態。
五、防火牆原則調控、高階服務管控與日誌追蹤
Windows
netsh advfirewall show allprofiles
【防火牆全域狀態】全面顯示網域 (Domain)、私有 (Private) 與公用 (Public) 三種環境下的防火牆實質啟閉狀態。
Windows
sc query type= service state= all
【全量底層服務清查】傾倒出系統上所有註冊的後台 Service，不論是執行中還是停止，用於排查是否有惡意驅動。
Windows
wevtutil qe Security /f:text /rd:true /c:10
【資安日誌即時鑑識】以反向倒敘 (最新優先) 自動抓取 Windows 安全性事件日誌 (Security Log) 的最後 10 筆明文。
Windows
route print -f
【高權限 - 路由重置】重置並清除系統非固定路由表。常用於拔除多重網卡或 VPN 斷線後的殘留路由干擾。
六、Linux 伺服器運維、安全防禦與連線統計
Linux
ss -tulpn
【核心 Socket 統計】快如閃電地印出 Linux 系統中所有處於監聽 (Listen) 的 TCP/UDP 埠口以及行程名稱。
Linux
sudo ufw status numbered
【帶編號的防火牆審查】列出 Ubuntu/Debian 架構下的 UFW 防火牆規則與其規則流水號，便於後續精準刪除規則。
Linux
iptables -L -n -v
【精細網卡流向審查】以數字格式(-n)不解析名稱，印出當前 Linux Netfilter 核心中最底層的防火牆規則與計數器。
Linux
journalctl -u ssh --since "1 day ago"
【SSH 暴破事件稽核】調閱過去 24 小時內 SSH 服務的所有登入日誌，用以檢查是否存在異常的暴力密碼試探。
